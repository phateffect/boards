补充（用户提供）：
- 有1个BOOT button 和1个RESET button
- 板载 1颗 ME6217C33M5G（3.3V LDO 稳压器；3V3(OUT) 即其输出）
- GPIO37 旁边有一个 "Dout" 焊盘（WS2812 矩阵数据输出，用于级联更多灯）

# 推断（LLM）：
# - GPIO14 = 矩阵 DIN（PIN_NEOPIXEL），被矩阵占用，故不在排针中
# - USB-C 接 ESP32-S3 原生 USB（D-/D+，通常 GPIO19/20，内部连接），用于供电+烧录(CDC)
# - UART0: TX=GPIO43, RX=GPIO44（已引出）
# - GPIO3 为 ESP32-S3 strapping 引脚，上电电平影响启动
